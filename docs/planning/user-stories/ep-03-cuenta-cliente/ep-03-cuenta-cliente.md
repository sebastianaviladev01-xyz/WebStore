# EP03 — Cuenta del cliente

- Índice: [Historias de usuario](../user-stories.md)
- Aplicación: Storefront
- Objetivo: [matriz de épicas](../user-stories.md#épicas)

## Resumen

Agrupa el registro con verificación por código, el inicio de sesión, la recuperación de contraseña y la edición o eliminación de la cuenta. La cuenta es opcional: un cliente puede comprar sin ella.
